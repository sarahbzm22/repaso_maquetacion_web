# repaso_maquetacion_web

Aquí tomamos apuntes y notas

Shift + tab = el código se mueve a la izq

<head></head> = configuración y cargar archivos externos.

<body></body> = todos los elementos de html que forman el layout de la web y que puede ver el usuario.

Abrir DevTools = clik derecho inspeccionar

Para hacer un comentario de código = Ctrl+ç

Para ajuste de línea = Alt+Z o en ViEW>>World wrap

Para bajar líneas y meterlas dentro de una caja, seleccionar las líneas y con Alt+(cualquiera de las flechas de arriba o abajo), hasta que se metan en la caja.
